# Mindora — static content

Public, data-only puzzle packs for Mindora. This repository contains no mobile application source, credentials, player accounts or saved games.

Each ZIP contains versioned puzzle data and tutorial definitions. `manifest.json` lists immutable archives; `manifest.sig` is its Ed25519 signature. The app checks the pinned public key, archive hashes, schemas, engine compatibility and puzzle validity before installation. Bundled puzzles and music remain playable offline.

Публичные статические наборы головоломок Mindora. Здесь нет исходников приложения, ключей, аккаунтов или сохранений игроков. Приложение проверяет подпись и целостность материалов. Обучение использует встроенные русские/английские тексты. Отдельные картинки для фона не используются.
